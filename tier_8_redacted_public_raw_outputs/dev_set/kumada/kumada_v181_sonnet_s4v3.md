### §A EP充填難易度の三群分類

**第一群（文献で明確に追跡可能）：** EP-03a, EP-04a, EP-06a, EP-05a, EP-09a

- **EP-03a** [Direct-observation / state-assignment pack]: Ni-ジホスフィン系のdiorganonickel中間体の分光学的同定・単離は、原論文グループ自身が後続Full Paperで実施しており、独立論文として追跡可能。
- **EP-04a** [Discrimination / replication pack]: ホモカップリング量の定量（cross:homo比）およびラジカル経路の検証（radical clock）は有機金属機構化学の独立研究テーマとして発表されやすい。
- **EP-06a** [Analogy-validation pack]: 触媒サイクルの素反応ステップ（OA, TM, RE）の動力学的解析は独立論文の主題として複数発表されており、文献検索で直接ヒットする。
- **EP-05a** [Quantitative-ranking substantiation pack]: 配位子系統的スクリーニング（収率比較）は原論文グループのFull Paperで実施済みの可能性が高く、追跡可能。
- **EP-09a** [Internal benchmark pack]: Ni(acac)₂（Corriu–Masse系）との直接比較は、後続のレビュー・比較論文で実施されている可能性が高い。

**第二群（間接的に追跡可能）：** EP-07a, EP-01a

- **EP-07a** [Boundary-test pack]: β水素排除回避の検証（deuterium labeling）は、原論文系そのものでの実施は限定的だが、類似Ni-アルキル系での研究（β-H排除の動力学）は豊富に存在する。
- **EP-01a** [Reporting-coherence pack]: 収率報告の整合化（全エントリ単離収率・内部標準明記）はFull Paper展開での自動解消が期待されるが、独立論文化されるというより原論文グループの後続論文に含まれる。

**第三群（充填が見つからない可能性あり）：** EP-08a

- **EP-08a** [Replication / uncertainty pack]: cis:trans比（80:20, 43:57）の反復測定・±SDの付与は、合成論文のFull Paperでも慣行的に省略されることが多く、インセンティブ構造的未充填パターンに該当する。この立体選択性データが後の研究で独立に再評価された可能性は低い（成功による問いの抹消: Ni-触媒クロスカップリングがstilbene合成ツールとして確立される前に、stilbeneの立体選択性問題は直接的な関心対象ではなくなった）。

### §D VQ階層と充填時間順序の対応分析

**充填の時間軸：**

- VQ-2 (Qualified)解除 要件: EP-01a → 1976年 [Tamao et al., BCSJ 1976] **自己充填 / Complete**
- VQ-3 要件（RI-05）: EP-05a → 1976年 [Hayashi et al., JACS 1976] **自己充填 / Complete**
- VQ-3 要件（RI-03 一部）: EP-03a → 1976年 [Tamao et al., BCSJ 1976] **自己充填 / Partial**
- VQ-3 要件（RI-07）: EP-07a → 1975年 [Yamamura et al.] **分野横断充填 / Indirect**（先行充填: 原論文より3年前から関連研究が存在）
- VQ-3 要件（RI-04, RI-06）: EP-04a / EP-06a → 1979年 [Tsou–Kochi] **分野横断充填 / Partial**
- VQ-4 要件（RI-09）: EP-09a → 1980年 [Kumada, Pure Appl. Chem.] **自己充填 / Indirect**
- VQ-4 要件（RI-08）: EP-08a → **未充填**（現在まで）

**階層-時間対応の評価：**

全体として「VQ階層が上がるほど充填に要する時間が長くなる」仮説を支持するパターンが観察される。VQ-2要件（EP-01a）は4年後に自己充填、VQ-3要件の主要部分（EP-05a）も同年に自己充填、VQ-3の独立検証（EP-04a）は7年後に分野横断充填、VQ-4（EP-09a）は8年後に間接充填という時間的勾配が確認できる。ただし例外として、VQ-2のEP-01aと同年にVQ-3のEP-05aも充填された点がある——これは不斉配位子開発という新研究目標が複数VQ要件を同時に充填したことを示す。

**特筆すべきパターン：**

1. **1976年の集中的自己充填**: 1972年原論文から4年後の1976年に、EP-01a・EP-05a・EP-03a（部分）が単一グループによって集中的に充填された。不斉クロスカップリング（Kumada–Hayashi反応）という新展開が充填の動機として機能した——これは「次世代研究目標の設定が前世代論文のEP充填を副産物として生み出す」パターンの典型例として記録できる。

2. **VQ階層逆転パターン（インセンティブ構造的逆転）**: 低VQ要件のEP-08a（RI-08: cis:trans比反復測定）が現在まで未充填である一方、より高VQ要件のEP-04a/EP-06a（RI-03/RI-04: 機構的証拠）が1979年に充填された。「科学的論理に基づくVQ充填順序（低VQ→高VQ）」と「出版インセンティブに基づく実際の充填順序（機構的問いを優先、統計的問いを放置）」の逆転パターンとして記録できる。

3. **著者回顧との照合**: Kumada 1980（Pure Appl. Chem.）レビューは触媒設計論（cis-intermediate）と合成的有用性を中心的回顧項目として論じており、ホモカップリング定量（EP-04a）やcis:trans統計的評価（EP-08a）への言及が回顧的に消失している可能性がある。これは「分野の内部者には不可視の構造的不在」の直接的証拠として機能する。

4. **先行充填の部分適用**: EP-07aに関連するβ-H排除研究（Yamamura 1975）は原論文（1972年）より3年後に発表されており、厳密な意味での先行充填には該当しないが、関連問題への独立研究が原論文と並行して進行していたことを示す。

### §E 未充填EPの発見的意義

**未充填EP一覧：**

**EP-08a [Replication / uncertainty pack]:**
* **未充填の理由**: インセンティブ構造的未充填 + 成功による問いの抹消の複合。cis/trans-1,2-dichloroethyleneからのstilbene形成という具体的な問いへの統計的再評価（n≥3、±SD）は技術的に容易だが、Ni-触媒クロスカップリングが一般合成ツールとして確立した後では独立論文化の動機が存在しない。またstilbene合成においてより効率的な手法（Pd触媒Heck反応等）の確立により、この特定基質での立体選択性統計の直接的需要が消滅した。
* **発見的意義**: あり。「anomalously enriched with the cis isomer」という著者自身の驚きの記述がありながら、その統計的有意性が50年以上問われなかったことは、合成化学論文の立体選択性報告慣行に関するUQSの発見として記録できる。Ni-触媒クロスカップリングの成功が「anomalous」な観察の統計的検証需要を消滅させたという逆説的構造が存在する。
* **将来の充填可能性**: 低（技術的には容易だが検証動機の欠如が障壁。フロー化学・自動合成プラットフォームを用いた条件系統的再評価の中で副産物的に充填される可能性はある）

**EP-04a（部分的未充填：Kumada系固有のcross:homo比定量）:**
* **未充填の理由**: インセンティブ構造的未充填。Kumada系での具体的なcross:homo比の数値は文献上明確に報告されたことがない可能性が高い。Pd系クロスカップリングへの関心移行（1970年代後半以降）により、Ni-dpe系固有のホモカップリング量定量は後回しになったと推定される。
* **発見的意義**: あり。「selective」という主張を50年以上定量的に裏付ける文献が存在しない（または確認困難）という事実は、クロスカップリング化学の成功が「selective」主張の検証需要を消滅させた典型例として記録できる。UQSが抽出したU-1（self-contradictory absence）が長期未充填として存続しているという発見は、原論文の証拠的空洞が現在まで埋められていないことを示す。
* **将来の充填可能性**: 中（現代のGC-MS技術と内部標準法で容易。Ni(I)/Ni(III)機構論争（2010年代以降）の文脈でcross:homo選択性の再評価が副産物的に充填される可能性がある）

**VQ階層逆転の診断：**
EP-08a（RI-08: 低VQ要件）とEP-04a部分（RI-04: cross:homo定量）が未充填のまま、EP-06a（RI-03/RI-06: より高VQ要件）がPd系の発展により間接充填されたことは、「科学的論理に基づくVQ充填順序（低VQ→高VQ）」と「出版インセンティブに基づく実際の充填順序（機構的問いを優先、データ品質・選択性定量を放置）」の明確な逆転パターンを示す。機構問題（RI-03, RI-04）は独立論文化されやすいが、データ品質問題（RI-08）と選択性の定量検証（RI-04の特定側面）は独立論文化されにくいというインセンティブ構造が、この逆転を50年以上維持している。
