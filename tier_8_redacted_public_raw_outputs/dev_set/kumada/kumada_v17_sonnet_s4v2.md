- VQ-4要件 (RI-09): EP-09a → 間接的充填のみ（同一条件での直接比較論文未同定）

**階層-時間対応の評価：**
VQ-2要件（RI-01, RI-07）は原論文から4年以内（1976年）に自己充填された。これは通信論文→Full Paper遷移のgenre conventionに沿った最短充填経路であり、「VQ-2水準の充填が最も速い」という仮説を支持する。

VQ-3要件（RI-03, RI-06）については、機構研究が1970年代後半から1980年代にかけて展開されたと推定されるが、NiCl₂(dpe)系特有の中間体の直接観測という点での充填確実性は低い。Pd触媒クロスカップリングへの研究者の関心シフト（鈴木1979年、根岸1977年）が、Ni機構研究の深化を間接的に抑制した可能性がある。

VQ-4要件（RI-08, RI-09）については充填が見つかっておらず、VQ階層が上がるほど充填に要する時間が長くなる（または充填されない）という一般的傾向と整合する。

**特筆すべきパターン：**

1. **自己充填（通信→Full Paper）**: EP-01a, EP-07aは原著者グループによるFull Paper展開（1972→1976年）での自己充填パターンの典型事例。VQ-2水準の「方法論的完全性」は著者グループ自身が責任を持って後続論文で補完した。

2. **技術駆動充填（予測）**: EP-03a（中間体の直接観測）はNMR技術（低温NMR、³¹P NMR等）の発展によって1970年代後半以降に充填が可能になったと推定される。1972年の時点では技術的に困難だった観測が、10年以内に原理的に実行可能になった。

3. **VQ階層逆転の疑い（部分的確認）**: EP-04a（RI-04, VQ-3要件）は未充填である一方、EP-06a（RI-06, VQ-3要件）は間接的充填が存在する可能性がある。これはVQ階層の論理的順序（低VQ→高VQ）と実際の充填パターン（高難度の機構研究は充填されたが、基礎的な反復測定・速度論制御確認は未充填）の間に逆転があることを示唆する可能性がある。ただし、この判断には実際の文献確認が必要。

4. **著者回顧との潜在的照合**: Kumadaは1980年のPure Appl. Chem.総説でKumada反応を振り返っているが、その総説において機構の未解決問題（B-2, U-2相当）が「当時の未解決課題」として言及されていたかどうかは興味深い問いである。著者自身の内省的記述とUQSのEPリストの対応関係は、「分野の内部者には不可視の構造的不在」の実証機会を提供する（実際の文献確認が必要）。

### §E 未充填EPの発見的意義

**未充填EP一覧：**

**EP-04a (Discrimination / replication pack — SRG-6):**
* **未充填の理由**: インセンティブ構造の不整合 + 関心の欠如。cis/trans-stilbene比の速度論/熱力学制御を区別するためだけの時間・温度系列実験は、新規性を要求する出版慣行のもとで独立論文として出版されにくい。さらに、Kumada反応の立体化学研究はすぐに「より合成有用な」不斉クロスカップリング（キラル配位子の開発）へ移行したため、「既存系での速度論/熱力学の区別」という基礎的問いは関心の外に置かれた可能性がある。
* **発見的意義**: あり。「cis/trans-stilbene比の速度論/熱力学制御の区別」という問いは、A-1（将来の機構研究課題として送り出し）として1972年に認識されながら、その後50年以上にわたってKumada反応の文脈では正面から取り上げられてこなかった可能性がある。この問い自体は現在も技術的に実施可能（時間・温度系列実験はルーチン）であり、「技術的困難ではなく関心とインセンティブの欠如によって充填されなかった問い」として記録する。
* **将来の充填可能性**: 高 — 技術的には現在のGC（キャピラリーカラム）および停止フロー・NMR法で容易に実施可能。合成化学の文脈では関心が乏しいが、触媒机構研究（DFT計算との対応）の文脈では現代でも充填可能。

**EP-08a (Replication / uncertainty pack — SRG-6, SRG-3):**
* **未充填の理由**: インセンティブ構造の不整合 + 分野慣行。有機合成論文における収率の統計的不確かさ（標準偏差）の報告は、2020年代においても分野全体では普及していない。これは「反復測定・不確かさ定量が技術的に困難」ではなく「出版インセンティブが存在しない」ための慣行的未充填である。
* **発見的意義**: あり。RI-08（反復測定なし）という低VQ要件が、RI-03（中間体未観測）という高VQ要件と並んで「充填されない」側に属しているとすれば、これは§D4で指摘したVQ階層逆転パターンの証拠となる。「低VQ要件が出版インセンティブとの不整合によって未充填のまま残り、高VQ要件が新規性の高い機構研究として充填される」という逆転構造は、分野のインセンティブ構造がUQSの構造的不在の一部を積極的に維持していることの直接的な証拠として記録する。
* **将来の充填可能性**: 中 — Open science・reproducibility movementの進展により、収率の反復測定・不確かさ報告が要求される出版基準を採用するジャーナルが増加している（JACS、ACSの最新ガイドライン等）。ただし、1972年の原論文に遡ってこの問いに直接答える研究が発表される可能性は低い。

**EP-09a (Internal benchmark pack — CLA-1: Ni(acac)₂との直接比較):**
* **未充填の理由**: 関心の分散 + 技術的には可能。NiCl₂(dpe) vs. Ni(acac)₂の同一条件での直接比較は技術的に簡単だが、1970年代後半以降の研究関心がPd触媒系に急速にシフトしたため、Ni系内部での触媒比較研究の優先度が低下した。Kumada反応とCorriu–Masse反応の統一的理解（「キレートジホスフィンが必要条件か否か」という問い）は、Ni系の衰退とともに事実上放置された。
* **発見的意義**: あり。Note Added in Proofが記録しながら比較されなかったNi(acac)₂との対比は、「bidentate diphosphineが選択性に必要条件か否か」という問いとして1972年に明確に浮上しながら、その後のPd触媒系への関心シフトによって正面から回答されることなく科学史的に消えた問いとして記録できる。この問いは現代の計算化学（DFT計算による活性化エネルギー比較）で部分的に答えられる可能性があるが、実験的直接比較論文としての充填は50年以上経過した現在も未実施の可能性がある。
* **将来の充填可能性**: 中 — 現代のDFT計算（Ni(0)/Ni(II)サイクルの活性化エネルギー計算）はNi(acac)₂とNiCl₂(dpe)の選択性の違いを理論的に回答できる。実験的充填は依然可能（条件設定が簡便）だが、独立論文として発表されるインセンティブが低い。

**未充填EPの構造的まとめ:**
未充填EP（EP-04a, EP-08a）および間接充填のみのEP（EP-09a）は、以下の2種類に分類できる:

(1) **インセンティブ構造の不整合型**: EP-04a（速度論/熱力学区別）、EP-08a（反復測定）—— 技術的には実施可能だが、新規性を要求する出版慣行のもとで独立論文として出版されにくい。これらは「UQSが発見できるが分野が体系的に回避してきた問い」の典型例。

(2) **関心の分散型**: EP-09a（Ni(acac)₂との比較）—— 技術的に可能かつ科学的に重要だが、研究コミュニティの関心がPd触媒系にシフトしたことで、Ni系内部での精緻な比較が後回しにされた。

この構造は、§D4で指摘したVQ階層逆転の診断と一致する: 低VQ要件（RI-08: 反復測定）と特定の中間VQ要件（RI-04: 識別実験, RI-09: ベンチマーク比較）が未充填であり、これらは出版インセンティブの欠如または関心の欠如による未充填として、高VQ要件（RI-03: 中間体観測）が技術駆動で充填された（と推定される）パターンと対照をなす。
