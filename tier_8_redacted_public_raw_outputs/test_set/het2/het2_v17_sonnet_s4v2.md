**階層-時間対応の評価：**

本論文の充填パターンは「VQ階層と充填時間の逆転」を示す典型例である。VQ-3要件（EP-03a, EP-06a）に対応する充填論文が2011〜2019年に既に存在する一方、VQ-2要件（EP-01a, EP-08a, EP-04a）の充填論文は現在まで存在しない。これは「VQ階層が高いほど充填に要する時間が長くなる」という仮説に反する。逆転の原因は分野のインセンティブ構造にある——operando EXAFS（EP-03a）やDFT計算（EP-06a）は機構的新発見として独立論文として発表しやすいが、反復測定（EP-08a）や採取条件の正規化（EP-01a）は独立論文の主題としては新規性が乏しく発表されにくい。

**特筆すべきパターン：**

- **技術駆動充填（2011〜2019）**: quick-scanning EXAFS（Reimann 2011）およびDFT/MD計算（Ramezani-Dakhel 2013、Polynski 2019）という新技術の登場がVQ-3要件を充填した。本論文はこれらの技術を本系（PdEnCat/FC-1001/Pd/Al₂O₃）に適用していない——「充填技術は存在するが適用されていない」という構造的不在。
- **自己充填（2018）**: Barreiro 2018（ref 28）は原著者グループによる自己充填であり、マルチスケールモデルをPdEnCat 30に適用した。しかし同グループが2024年の本論文でFC-1001・Pd/Al₂O₃にモデルを拡張していないのは、自己充填の「選択的不完全性」を示す。
- **VQ逆転充填（診断確認）**: VQ-2要件の未充填とVQ-3要件の（部分的）充填済みの共存は、Stage 3 §6で述べた「出版インセンティブに基づく実際の充填順序（高VQ→低VQ）」の逆転パターンを確認する。これはUQSが§Eの「VQ階層逆転の診断」として体系化している発見的パターンの明確な事例となる。

### §E 未充填EPの発見的意義

**未充填EP一覧：**

**EP-01a [Reporting-coherence pack]（U-3: コンフィギュレーション間ICP比較の正規化）:**
* **未充填の理由**: インセンティブ構造の不整合——コンフィギュレーション1とコンフィギュレーション2の採取条件正規化は、本論文固有の報告形式問題（RI-01）に起因する。この種の正規化記述を主テーマとした独立論文は新規性をもたないため出版されにくい。著者グループの後続論文またはCorrigendumでの自己解消がない限り永続的に未充填となる可能性が高い。
* **発見的意義**: あり — 「論文の最重要定量的結論（NEt₃最大原因説）を支える182 vs. 194 ppmの数値比較が正規化基盤を欠いている」という事実は、2026年現在でも分野において認識されておらず、独立した検証実験なしにはその定量的正当性が評価できない。これは「出版後に被引用されるが原理的に独立検証不能な定量的クレーム」の事例として記録できる。
* **将来の充填可能性**: 中（原著者グループまたは批判的追試論文による自己充填または訂正充填は技術的に容易だが、発表インセンティブが低いため実現は偶発的）

**EP-08a [Replication / uncertainty pack]（B-17: 反復実験なし）:**
* **未充填の理由**: インセンティブ構造の不整合 + 分野慣行 — 既存ICP値の反復測定は「新規性なし」とみなされ独立論文として発表されにくい。フロー触媒研究においては単一実験の定量的結果を報告する慣行が継続しており、この問題は分野として体系的に回避されてきた。
* **発見的意義**: あり — 本論文の全ICP値が単一実験値であるという事実は、被引用論文の後続研究者が「182 ppm」「6 ppm」という数値を固定した事実として引用する連鎖を生む。反復実験による不確かさ評価なしに定量値が科学的事実として確立されていくプロセスの事例として記録できる。
* **将来の充填可能性**: 低（分野の出版インセンティブ構造が変わらない限り、単独の反復測定論文は出版されにくい；ただし後続のfull studyに組み込まれる形での充填は中程度の可能性がある）

**EP-04a [Discrimination / replication pack]（SRG-1: 実験独立性の未確認）:**
* **未充填の理由**: インセンティブ構造の不整合 — 「既存論文の実験が新鮮な触媒床で行われていたかどうかの確認実験」は独立論文として発表されない。著者グループの自己充填（後続論文での明示的記述）が唯一の現実的充填経路。
* **発見的意義**: あり — 本論文の中心的主張（成分帰属）が成立するための必要条件（実験独立性）が報告されていないことは、被引用研究者がこの前提を確認できないまま結果を利用する状況を生む。これは「前提条件が未報告のまま定量的主張が流通する」パターンの事例として記録できる。
* **将来の充填可能性**: 中（著者グループが後続論文でフレッシュベッド使用を明示的に記述する可能性はある；分野の実験設計報告標準が強化されれば義務化される性質の記述でもある）

**EP-07a [Boundary-test pack]（B-9: 再吸着排除主張）:**
* **未充填の理由**: 技術的困難 + 関心の欠如 — スパイキング実験による再吸着測定は技術的には実行可能だが、「再吸着は有意でない」という否定的結果を確認するだけの実験は新規の機構的発見を生まないため論文化しにくい。boomerang catalysisの文献（Gruttadauria 2013, ref 56）は概念的に整理するが、本系固有の定量的検証はない。
* **発見的意義**: あり — 本論文の「ICP値は不可逆的リーチングを定量する」という解釈の前提が実験的に未検証であることは、全ICP値の解釈に基礎的不確実性を残す。特に「boomerang catalysis is not likely to be significant」という境界主張が2024年時点で実験的根拠を持たないことは、RI-07の境界主張パターンの典型例として記録できる。
* **将来の充填可能性**: 中（既存のフロー触媒研究インフラで実行可能；Kappe・de Bellefon・Köhlerグループが類似系で行う可能性はある）

**EP-06a [Analogy-validation pack]（SRG-5: Scheme 2低温適用；SRG-4: PdO表面のArI誘起リーチング機構）:**
* **未充填の理由（SRG-5）**: インセンティブ構造の不整合 + 関心の欠如 — ポリウレア内包Pd(OAc)₂の30°Cでの反応速度測定は産業的関心（低温リーチング制御）と対応するが、「既知機構の適用限界の再検討」として新規性が限定的とみなされる。ホスフィン配位の影響（B-12）も同様の理由で未検討。
* **未充填の理由（SRG-4/PdO）**: 技術的困難 — PdO表面層を持つPd/Al₂O₃のArI誘起リーチング機構（PdO→Pd(0)還元ステップの実証）はin situ time-resolved XANESまたはXPSが必要な専門的実験であり、触媒化学×表面科学の境界領域に位置する。対応する専門グループ（Heinz、Ananikov）がPd(0)系に注力してきた結果、PdO系が空白として残っている。
* **発見的意義**: あり（SRG-4/PdO）— 「Pd/Al₂O₃のPdO表面からのArI誘起リーチングがPd(0)→OA経路では説明できない」という自己矛盾的不在（U-2）は、論文が2024年現在も解消されていない。これは「論文自身の記述と提案機構の矛盾が出版後も分野で認識されていない」状況の事例として記録できる。
* **将来の充填可能性**: SRG-5: 高（産業的モチベーションがあり既存Pd化学インフラで実行可能）；SRG-4/PdO: 中（専門的シンクロトロン実験が必要だが、2024年以降のoperando XASの普及で可能性は増している）
