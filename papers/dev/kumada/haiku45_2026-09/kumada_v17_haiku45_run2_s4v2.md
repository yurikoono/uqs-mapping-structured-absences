## §A EP充填難易度の三群分類

**第一群「文献で明確に追跡可能」:**
- EP-02a [Identity / purity substantiation pack]: 1972年以降の Ni-ホスフィン系クロスカップリング論文では、生成物の NMR・MS が報告基準として定着。明確に検出可能。
- EP-03a [Direct-observation / state-assignment pack]: 1980年代以降の in situ NMR および低温 NMR による Ni-alkyl/Ni-aryl 中間体の直接観測は、Kumada group 自身および others の独立論文として存在。
- EP-07a [Boundary-test pack]: Ni-ホスフィンのスコープ系統的拡張・限界探索は多数の論文で。
- EP-10a [Kinetic verification pack]: 触媒的 Ni-mediated C-C coupling の速度論研究は 1970年代後期–1980年代に複数報。

**第二群「間接的に追跡可能」:**
- EP-01a [Reporting-coherence pack]: Yield definition の統一は、journal editorial standards の変化として textbook・総説に反映。独立論文としての「報告統一」は少ない。
- EP-06a [Analogy-validation pack]: Ni-catalyzed coupling の mechanism validation は、類似の Pd/Pt systems との比較で部分的に論じられるが、Ni-specific stoichiometric studies は限定的。
- EP-08a [Replication / uncertainty pack]: Replicate data + SD 報告の慣行は、journal policy shift の形で reflective だが、直接的な「再現性研究」独立論文は希。

**第三群「充填が見つからない可能性あり」:**
- RI-01 pure reporting consistency (EP-01a の一部): 「yield definition の retrospective 統一」は科学的内容ではなく、reporting convention の変遷。独立論文として充填されない。
- RI-08 (era-norm tolerated の低優先度項目): 1970年代の communication format での single data point 報告を「現代基準で充填」する独立論文は概ねなし。これは format change の帰結であり科学的検証の対象外。

## §D 充填マップの制約と不確定性

**既知の limit:**

1. **Confidence level の low-medium territory**: B-2, B-4 について、具体的論文の特定が Claude LLM の domain knowledge に制限される。「Kumada group による systematic kinetic study」は歴史的事実として推定されるが、**具体的 publication の title/year/journal の逐語的確認は neural hallucination risk あり**。

2. **Publication lag と format constraint**: Kumada 1972 が communication → fuller reporting は 1973–1975 in successive full papers として fractured publication。複数年・複数論文にわたる段階的補強のため、「単一の充填論文」として one-to-one mapping は不可。

3. **Era-norm の「許容から不足へ」の転換**: RI-01 (reporting consistency), RI-08 (replication standards) の recovery は、individual papers でなく journal policy / field convention shift として observed。Specific「充填論文」は存在しない可能性あり。
