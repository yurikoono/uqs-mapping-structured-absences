# Input-ablation control (`papers/ablation_provenance/`, SI-11.19)

Materials for the pre-registered provenance ablation (Arm P = PDF input vs Arm W = bibliographic stub; 6 papers × 2 arms × 3 runs = 36 runs; v18.4 + Sonnet 4.6, Stages 0–2; pre-registration `_preregistration_paperA_20260809.md`). The runs are included in this package and reported in SI-11.19: 228 files in `papers/ablation_provenance/` (counted when this package was built), with the matchers used for scoring under `_scoring/`. The project memo that first summarised the results (`improvements/_methodology/ablation_results_paperA_20260810.md`) is not deposited. The 7 `.txt` files under `_run_kit/` (`KICKOFF_PROMPT.txt`, `stub_app1.txt`, `stub_app2.txt`, `stub_hom2.txt`, `stub_kumada.txt`, `stub_murai.txt`, `stub_scr2.txt`) are author-written bibliographic stubs and the session kick-off prompt, not source text. The SHA-256 of every file is listed in `CHECKSUMS.sha256` at the package root.
